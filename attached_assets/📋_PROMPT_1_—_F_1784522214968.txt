## Prompt 2: Genre × Theme Combo Table

- Create `THEME_COMBO_TABLE` object structured as `{ genre: { theme: multiplier } }`
- Multipliers follow same scale: **1.5 (PERFECT), 1.0 (GOOD), 0.6 (BAD FIT)**
- Example logic:
  - "Romance" + "Slow Burn" = 1.5 (PERFECT)
  - "Horror" + "Forbidden Love" = 1.5 (PERFECT)
  - "Sports" + "Amnesia" = 0.6 (BAD FIT)
- Export `getThemeComboResult(genre, theme)` function (matching `getComboResult()` pattern)

## Prompt 3: Type × Theme Bonus Table

- Create `TYPE_THEME_BONUS` object: `{ type: { theme: bonus } }`
- Small bonuses only: +0.05 to +0.10 multiplier (secondary bonus)
- Example:
  - Mini Series excels with: Mystery, Psychological, Slice of Life (+0.05)
  - Series excels with: Drama, Historical, Coming-of-Age (+0.05)
  - Movie excels with: Action, Thriller, Sci-Fi (+0.05)
- Export `getTypeThemeBonus(type, theme)` function returning bonus value
