PROMPT 6: Events System — Overhaul

6.1 Happiness recovery on good outcomes
- Add +happiness to actors when player accepts events with good conditions.
- Applies to: CP events, solo events, high-rated productions (B/A/S), etc.
- Replit: create happiness bonus formula based on event type and outcome.

6.2 Remove Negotiate option
- Change all event modals from Accept / Negotiate / Decline to Accept / Decline only.
- Remove negotiate functionality entirely from event system.
- Keep existing Accept/Decline logic, adjust penalties/bonuses accordingly.

6.3 Remove invalid CP formation events
- If two actors are already a fixed CP, do not show events suggesting they can form a CP with other actors.
- Only show CP formation events for: actors with no CP, or actors with unfixed CPs.

6.4 Sponsorship Event — Money Threshold
- Sponsorship events only appear if company money is 50,000 or below.
- If money is above 50,000, sponsorship events do not trigger.
- Exact threshold: ≤50,000 = can trigger, >50,000 = never trigger.

6.5 Tricky Events (30% chance)
- Add new "tricky choice" events where both Accept and Decline have mixed outcomes:
  - Example: Accept = +chemistry but -reputation, Decline = +reputation but -chemistry
  - Example: Accept = +money but -actor happiness, Decline = +happiness but -money
- Occurrence rate: 30% of all events.
- Remaining 70%: Standard events — 40% good conditions, 30% bad conditions.
- Tricky events display a ⚠️ "Risky Choice" badge in the modal.
- Replit: create 5-10 tricky event templates with balanced trade-offs.
